# ネットワークについて

PC間での通信はネットワークインターフェースを通して行われる。
`LAN(Local Area Network)`とはPCをスイッチに接続し、他PCと接続するネットワークのこと。

`同一LAN`内では`直接通信が行える。`
`別LAN` or `インターネット`では`ルータを経由して通信を行う`

---

## 名前解決を行う

- Linuxコマンドは以下

```bash
dig "host名"
```

## sshについて

パスワード認証/公開鍵認証を行うことができる。
公開鍵の作り方について書いてみる。
手順は以下である。

1. 秘密鍵/公開鍵を作成する`(クライアントで作成)`
2. 作成した`公開鍵`を接続先の`サーバ`に格納する
3. 接続する

```bash
# 1.秘密鍵/公開鍵(.pub)を作成する
# デフォルト .sshディレクトリに id_rsa(秘密鍵)/id_rsa.pub(公開鍵)が作成される
ssh-keygen

# 2.　接続先に公開鍵を設置する(手段は2つ)
# 2.1 ssh-copy-idコマンドを使う(クライアントで実行できる)
ssh-copy-id "接続先リモートホスト"

# 2.2 先ほど作った公開鍵（id_rsa.pub）の記述をそのままコピペする 
.ssh/authorized_keys

# 3. sshで接続する。(秘密鍵を指定して接続する)
ssh -i ~/.ssh/id_rsa user@hostname 
ssh -i "<キー>.pem" user@host
```
