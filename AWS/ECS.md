# ECS

## ECSの用語について
- [ECM/Sercvice公開方法]
  - WebAppの公開は`Express`,`Service`を利用するのが一般的。
    Serveiceはタスク/VPCなどをして指定して公開するため、タスクの数を指定しておけば、タスクが落ちても自動で再起動してくれる。そのため、Expressよりも設定に気をつける必要があるが、安定した公開が可能となる。
  - Expressはタスク/VPCなどをして指定して公開するため、タスクの数を指定してないが公開が簡易であるため、テスト環境などで利用されることが多い。
  
- Task(タスク)
  - EC2インスタンス上で実行されるコンテナのこと(🚨EC2インスタンス上でコンテナを起動している)
  - EC2ではインスタンス単位でIAMロールの設定しかできないが、ECSではTask単位で設定できる
  - Task Definitionで定義する

- Cluster(クラスター)
  - EC2インスタンスのこと、Taskを複数実行できる

- Service(サービス)
  - Webサーバなど同じタスクをELBで分散したい場合などにServiceという

- Fargate
  - Cluster用のEC2インスタンスを用意せずにコンテナを動かせるサービス
    (EC2インスタンスの管理が不要となる)
